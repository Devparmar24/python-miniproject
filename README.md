# Automated Student Report Card & Email System

A Python-based desktop application built with Tkinter, Pandas, and Matplotlib. This system provides a role-based portal for students to view their academic performance and for instructors to manage records and send automated report card emails. 

## 🚀 Features
* **Role-Based Login:** Separate secure portals for Students and Instructors.
* **Student Dashboard:** Students can view their marks across 4 subjects (Python, EDC, DSD, Maths 3), total score, and estimated GPA.
* **Performance Analytics:** Interactive Matplotlib graphs comparing individual student scores against the class average and the highest-performing peer.
* **Instructor Panel:** A data table for the instructor to view all students and track who has received their report card.
* **Automated Emailing:** One-click email system that generates and sends (or simulates) a formatted report card to the student's email address.
* **CSV Database:** Lightweight and easily editable data management using `pandas`.

## 🛠️ Technologies Used
* **Python 3**
* **Tkinter:** Graphical User Interface (GUI)
* **Pandas:** CSV Database management and data processing
* **Matplotlib & NumPy:** Data visualization and graphing
